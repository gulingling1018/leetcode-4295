# 12 周训练计划（Java/C++ + SQL）

目标：让 0 基础学习者在 12 周后可独立完成 90% 常见题型。

## 1. 每周固定节奏

- 算法主线：`5 天/周`
- SQL 专线：`2 天/周`（也可每天加 1~2 题）
- 每天流程：
  1. 复盘昨天错题（20 分钟）
  2. 新题训练（90 分钟）
  3. 讲解输出（30 分钟，按基础/熟练/资深）

## 2. 周计划

### 第 1-2 周：编程基础 + 数组字符串

- Java/C++ 语法、容器、函数
- 题型：数组遍历、哈希查找、字符串处理
- 目标：能稳定 AC Easy

### 第 3-4 周：双指针/窗口/前缀和 + 链表

- 题型：两数/三数、最短子数组、链表反转与合并
- 目标：开始攻克中等题

### 第 5-6 周：栈队列 + 树遍历 + BFS/DFS

- 题型：括号、层序遍历、岛屿、课程表
- SQL：基础查询 + 简单 JOIN

### 第 7-8 周：回溯 + 二分 + 贪心

- 题型：组合/排列、边界二分、区间贪心
- SQL：分组聚合 + `HAVING`

### 第 9-10 周：动态规划专题

- 线性 DP、背包、区间 DP
- SQL：窗口函数（排名、累计）

### 第 11 周：综合周

- 算法混合题（树图 + DP）
- SQL 业务分析题（日期、留存、多表）

### 第 12 周：模拟面试周

- 每天 3 题算法 + 2 题 SQL
- 题后必须口述三层解法与复杂度

## 3. 每题输出标准（必须执行）

1. 基础解法：保证正确，代码可运行
2. 熟练解法：主流最优，边界完整
3. 资深解法：讨论工程可维护性和性能取舍
4. 语法/API 解释：把每个关键函数讲清楚

## 4. 阶段验收

- 第 4 周：Easy 独立通过率 `>= 85%`
- 第 8 周：Medium 独立通过率 `>= 65%`
- 第 12 周：综合通过率（含 SQL）接近 `90%`

## 5. 语言选择建议

- 主语言二选一：Java 或 C++
- 另一语言每周至少 2 次“同题复写”
- SQL 不分语言，必须长期稳定训练
