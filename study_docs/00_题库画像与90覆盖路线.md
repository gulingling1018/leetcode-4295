## 4. 90% 覆盖学习架构

把题型压成 8 个模块，按顺序学：

1. 数组 + 字符串 + 哈希
2. 双指针 + 滑动窗口 + 前缀和
3. 链表 + 栈 + 队列
4. 二叉树 + BST + 递归回溯
5. 图 + BFS/DFS + 并查集/拓扑
6. 二分 + 贪心 + 堆（优先队列）
7. 动态规划（线性/背包/区间）
8. SQL 专题（JOIN/GROUP/WINDOW/CTE）

建议占比（时间）：

- 数据结构与算法：`75%`
- SQL：`25%`

## 5. 过关标准（0 基础版）

每个模块都用同一标准：

- 基础：能写出可运行的暴力或直接解法，能解释时间复杂度。
- 熟练：能在 20~35 分钟内写出主流最优解，边界用例完整。
- 资深：能给出 2 种以上解法，说明取舍（可读性/性能/实现复杂度）。

最终目标：在中等题为主的真实刷题环境中，`90%+` 题能独立完成或在少量提示下完成。
