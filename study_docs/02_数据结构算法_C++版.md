# 数据结构算法学习手册（C++ 版，0 基础）

## 1. 先掌握的 C++17 语法

必须会：

- 基础类型：`int long long double bool char string`
- 容器：
  - `vector<int>`
  - `unordered_map<int, int>`
  - `unordered_set<int>`
  - `queue<int> / deque<int> / stack<int>`
- 控制流：`if/for/while`
- 函数：`int f(int x) { ... }`
- 结构体：`struct ListNode { int val; ListNode* next; };`

常用 STL 函数：

- `v.push_back(x)`：尾插
- `v.size()`：长度
- `sort(v.begin(), v.end())`：排序
- `mp.count(k)`：键是否存在
- `mp[k]`：读写值（不存在会默认构造）
- `q.push(x) / q.front() / q.pop()`：队列

## 2. 模块一：数组/字符串/哈希

代表题：`1 3 14 49 209`

### 基础解法

- 先用双循环保证正确性，别急着优化。

### 熟练解法

- `unordered_map` 做查找加速。
- 排序 + 双指针处理和、区间、去重类问题。

### 资深解法

- 为每类题沉淀固定模板（两数和、滑窗、前缀和）。
- 明确哈希冲突与最坏复杂度风险。

示例（两数之和）：

```cpp
vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int, int> pos;
    for (int i = 0; i < (int)nums.size(); ++i) {
        int need = target - nums[i];
        if (pos.count(need)) return {pos[need], i};
        pos[nums[i]] = i;
    }
    return {-1, -1};
}
```

语法与函数详解：

- `unordered_map<int, int>`：哈希表，平均 `O(1)` 查找。
- `pos.count(k)`：返回 `0` 或 `1`（是否存在）。
- `return {a, b};`：返回 `vector<int>` 初始化列表。

## 3. 模块二：链表/栈/队列

代表题：`2 19 21 206 232`

### 基础解法

- 链表先画图，再写指针移动顺序。

### 熟练解法

- 使用哨兵节点（dummy）消除头节点特判。
- 用 `stack` 处理括号，`deque` 处理单调队列。

### 资深解法

- 注意内存与生命周期，避免悬空指针。
- 能写出迭代与递归两个版本并比较风险。

## 4. 模块三：树/图/搜索

代表题：`94 102 104 199 200 207`

### 基础解法

- 树用递归；图用 DFS/BFS。

### 熟练解法

- 邻接表：`vector<vector<int>> g(n);`
- 拓扑排序：入度数组 + `queue<int>`。

### 资深解法

- 根据数据规模切换：
  - 稀疏图：邻接表
  - 稠密图：邻接矩阵
- 用位运算/状态压缩优化搜索空间。

## 5. 模块四：二分/回溯/动态规划

代表题：`33 39 46 70 198 300`

### 基础解法

- 二分先写循环不变量。
- 回溯先写终止条件。
- DP 先明确定义状态。

### 熟练解法

- 二分写成函数模板，避免边界错。
- 回溯做去重剪枝。
- DP 做滚动数组优化空间。

### 资深解法

- 从“状态机”角度解释 DP。
- 对比记忆化搜索和自底向上 DP 的成本。

## 6. C++ 常用函数与坑点

### 排序与比较器

```cpp
sort(a.begin(), a.end(), [](const auto& x, const auto& y) {
    return x[0] < y[0];
});
```

- `const auto&`：避免拷贝
- 比较器必须满足严格弱序

### 优先队列

- 小根堆：
  ```cpp
  priority_queue<int, vector<int>, greater<int>> pq;
  ```
- 大根堆（默认）：
  ```cpp
  priority_queue<int> pq;
  ```

### 字符串

- `s.substr(pos, len)`
- `stoi(s)`：字符串转整数
- `to_string(x)`：整数转字符串

## 7. 每题作答模板（固定流程）
